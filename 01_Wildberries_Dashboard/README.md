## 📌 О проекте
Интерактивный двухстраничный дашборд для владельца магазина на Wildberries, позволяющий в реальном времени отслеживать эффективность продаж и окупаемость рекламы.

* **Индустрия:** E-commerce / Маркетплейсы
* **Стек:** Power BI Desktop, DAX, Figma, Excel
* **Результат:** Сокращение времени на анализ данных с 40 до 3 минут и экономия ~18% рекламного бюджета в первый месяц.

## 🎯 Бизнес-задачи
1. **Консолидация:** Сбор разрозненных отчетов (продажи, реклама, логистика) в единую модель данных.
2. **Расчет ДРР:** Автоматизация расчета доли рекламных расходов (ДРР) по каждой категории товаров.
3. **UX/UI:** Создание нативного интерфейса, понятного бизнесу без подготовки.

## 🏗️ Архитектура и модель данных
В основе проекта лежит схема **«Звезда» (Star Schema)** для высокой производительности и точности расчетов.

### Ключевые решения:
* **Bridge Table:** Реализована таблица-мост для связи рекламных кампаний с категориями, что решило проблему неоднозначности путей (Path Ambiguity).
* **Custom Calendar:** Кастомная таблица периодов для фильтрации по специфическим неделям отчётности Wildberries.

> **Сложность:** Рекламная кампания может охватывать несколько категорий сразу.
> **Решение:** Использование Bridge Table позволило корректно распределять расходы пропорционально выручке каждой категории.

## 📊 Логика расчетов (DAX)
Реализована цепочка мер для анализа всей воронки продаж:
`Показы → CTR → Клики → CPC → Расходы → CPO → Заказы → ДРР → Выручка`.

**Примеры ключевых метрик:**
* **ДРР (%)** — мониторинг окупаемости рекламы в реальном времени.
* **Выкупаемость (%)** — расчет реальной прибыли с учетом логистики и возвратов.

## 🖼️ Визуализация и UX
Дашборд состоит из двух экранов:
1. **Обзор продаж:** KPI-блоки, динамика выручки и детализация по артикулам.
2. **Анализ рекламы:** Воронка эффективности и сводная таблица кампаний с условным форматированием.

*Особенности дизайна:*
* **Theme JSON:** Единая цветовая палитра и шрифты для всех визуалов.
* **Интерактив:** Боковая панель фильтров и навигация через кнопки с эффектами Hover/Pressed.

## 💡 Ключевые инсайты
* **Индивидуальный ДРР:** Выявлено, что для каждой категории товаров нужен свой порог окупаемости (от 5% до 20%).
* **Анализ выкупаемости:** Обнаружены артикулы с высокой выручкой, но отрицательной прибылью из-за низкого процента выкупа (38%).
* **Усталость рекламы:** Установлено, что эффективность большинства кампаний падает после 14 дней работы.

## 📈 Результаты для бизнеса
* **Экономия:** Снижение неэффективных трат на рекламу на **18%**.
* **Прозрачность:** Единый источник правды для планирования поставок и закупок.
