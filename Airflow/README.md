# Автоматизация ETL-процессов для E-commerce аналитики на Apache Airflow

В рамках развития аналитической инфраструктуры компании я спроектировал и внедрил автоматизированный конвейер обработки данных для интеграции с API Wildberries. Основной целью проекта являлась минимизация ручного труда при подготовке отчетности и обеспечение высокой точности данных в BI-системе.

## Техническая реализация

Техническая реализация проекта базируется на использовании Apache Airflow, развернутого в изолированной контейнерной среде Docker, что позволило обеспечить воспроизводимость пайплайна и простоту его обслуживания.

Разработанный ETL-процесс состоит из последовательных этапов:

1. Извлечение сырых данных из внешнего API Wildberries
2. Предобработка и валидация данных
3. Трансформация данных под аналитическую модель
4. Инкрементальная загрузка данных в PostgreSQL с использованием метода `UPSERT`

Особое внимание было уделено отказоустойчивости системы. Для этого были реализованы:

* механизмы повторных попыток выполнения задач (`retry policy`)
* автоматическая отправка уведомлений при возникновении инцидентов
* логирование этапов выполнения ETL-процесса

## Интеграция с BI-системой

Интеграция пайплайна с Power BI через API-триггеры позволила добиться актуализации отчетности в режиме, близком к реальному времени. Это позволило исключить задержки при принятии бизнес-решений и повысить оперативность аналитики.

## Результаты внедрения

Внедрение решения позволило:

* полностью исключить человеческий фактор при обновлении витрин данных
* сократить время подготовки отчетности
* повысить стабильность аналитической инфраструктуры
* высвободить ресурсы команды для углубленного анализа маржинальности и оптимизации складских запасов

## Используемый стек технологий

* Python
* Apache Airflow
* Docker
