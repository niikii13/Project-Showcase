# Data Analytics & Automation Portfolio

Добро пожаловать в мой репозиторий-портфолио. Здесь собраны комплексные кейсы, демонстрирующие мои навыки в области сквозной аналитики, проектирования пайплайнов данных (ETL) и автоматизации рутинных бизнес-процессов.

---

## 🚀 Основные проекты

### 📊 Бизнес-аналитика и Дашборды (SQL & Power BI)

* **[Анализ бразильского маркетплейса Olist](./olist-ecommerce-analytics/)**
    * **Задача:** Сквозной анализ e-commerce датасета: очистка геоданных, обработка связанных таблиц.
    * **Стек:** SQL (сложные агрегации, оконные функции), Power BI (DAX, кастомный дизайн UI/UX).
    * **Результат:** Интерактивный многостраничный дашборд для отслеживания ключевых метрик продаж и логистики.
* **[Анализ продаж и рекламы Wildberries](./wildberries-sales-dashboard/)**
    * **Задача:** Сбор и визуализация данных для магазина на маркетплейсе.
    * **Стек:** Power BI, расчет юнит-экономики, моделирование ad-costs.
    * **Результат:** Дашборд для контроля окупаемости рекламы, ДРР и операционного оборота магазина.

### ⚙️ Автоматизация процессов и ETL (Google Apps Script)

* **[ETL: Автоматизация лидов Avito](./avito-leads-etl/)**
    * **Задача:** Трансформация агрегированных отчетов Avito в атомарную CRM-базу (1 строка = 1 лид) для отдела продаж.
    * **Стек:** Google Apps Script (JavaScript), Unpivoting алгоритмы, дедупликация на базе составных ключей.
    * **Интерфейс:** [Открыть интерактивную таблицу ↗](ССЫЛКА_НА_ВАШУ_ТАБЛИЦУ_АВИТО) *(Режим чтения)*
* **[Risk Management: Мониторинг букмекерской линии](./betting-risk-monitor/)**
    * **Задача:** Автоматический поиск операционных аномалий («вилок») и валидация спортивных исходов в реальном времени.
    * **Стек:** Google Apps Script, математическое моделирование маржи (двух- и трехисходные рынки).
    * **Интерфейс:** [Открыть интерактивную таблицу ↗](ССЫЛКА_НА_ВАШУ_ТАБЛИЦУ_БЕТТИНГА) *(Режим чтения)*

## 🛠️ Технологический стек

* **Работа с данными & SQL:** Написание сложных запросов, фильтрация, агрегация, выявление дубликатов, dynamic columns search.
* **BI-инструменты:** Развертывание систем метрик в Power BI, построение связей между таблицами, написание мер на DAX, проектирование эргономичных интерфейсов (Figma).
* **Программирование & Автоматизация:** Написание скриптов автоматизации на JavaScript (Google Apps Script), манипуляции с UI таблиц, оптимизация алгоритмов обработки массивов данных (1000+ строк менее чем за 3 секунды).
