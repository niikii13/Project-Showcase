## 📦 Аналитика маркетплейсов (Wildberries)
Инструментарий для мониторинга показателей магазина на Wildberries.

* **Задача:** Создать единое окно мониторинга выручки и рекламных расходов.
* **Решение:** * Разработан дашборд в **Power BI** с кастомным дизайном из Figma.
    * Реализована сквозная аналитика: от показов рекламы до чистой прибыли.
* **Результат:** Автоматизирован расчет ROI по каждой категории товаров.

## 🇧🇷 E-commerce анализ (Olist Brazil)
Глубокий анализ открытого датасета бразильского маркетплейса Olist.

* **Задача:** Проанализировать географию продаж и выявить узкие места в логистике.
* **Решение:** * Обработка данных (100к+ заказов).
    * Создание интерактивной карты продаж.
    * Классификация товаров с помощью ABC-анализа.
* **Инструменты:** Power BI, SQL.
