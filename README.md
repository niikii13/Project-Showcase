## 📦 Аналитика маркетплейсов (Wildberries)
Инструментарий для мониторинга показателей магазина на Wildberries.

**Задача:** Автоматизировать сбор данных из API, исключить ручной ввод и обеспечить ежедневную актуализацию аналитических дашбордов.

**Решение:**
  Инженерная часть
Спроектировал и развернул ETL-пайплайны на Apache Airflow в контейнерной среде Docker. Реализовал:
* инкрементальную загрузку данных в базу данных
* автоматизированную обработку данных из API
* мониторинг качества данных
* обработку ошибок и механизм повторных попыток выполнения задач

Аналитическая часть
Разработал аналитический дашборд в Power BI с кастомным дизайном. Настроил автоматические API-триггеры для обновления отчетности и синхронизации данных в режиме, близком к реальному времени.

**Результат:**
* время подготовки отчетности сокращено до нуля
* исключены ошибки ручного ввода
* обеспечена актуальность данных в режиме реального времени
* повышена стабильность и прозрачность аналитической отчетности

## 📈 Анализ продаж онлайн-ритейлера (Tableau)
Разработка интерактивного дашборда для анализа эффективности продаж и сегментации клиентов.

* **Задача:** Визуализировать ключевые показатели бизнеса, выявить сезонность и оценить лояльность клиентов.
* **Решение:** * Проведена предобработка данных (Cleaning & Aggregation).
    * Созданы сложные вычисляемые поля (Customer Loyalty, Net Revenue).
    * Спроектирован интерактивный дашборд с кросс-фильтрацией (тренды, география, топ товаров).
* **Результат:** Создан инструмент анализа, который позволяет мгновенно оценивать Retention и выявлять товары-бестселлеры.
